# Meltiew: download

Version 1.9.1. Same account and friends on every platform.

| Platform | File |
| --- | --- |
| Android 7+ | [meltiew.apk](https://github.com/narezy/Meltiew/raw/refs/heads/download/meltiew.apk) |
| Windows (64-bit) | [meltiew-windows.zip](https://github.com/narezy/Meltiew/raw/refs/heads/download/meltiew-windows.zip) |
| Linux (x86_64) | [meltiew-linux.zip](https://github.com/narezy/Meltiew/raw/refs/heads/download/meltiew-linux.zip) |
| macOS (beta, Apple Silicon and Intel) | [meltiew-macos.zip](https://github.com/narezy/Meltiew/raw/refs/heads/download/meltiew-macos.zip) |
| iPhone / iPad (beta, iOS 16+) | [meltiew-ios.ipa](https://github.com/narezy/Meltiew/raw/refs/heads/download/meltiew-ios.ipa) |
| VR headsets: Pico 4, Meta Quest (beta) | [meltiew-vr.apk](https://github.com/narezy/Meltiew/raw/refs/heads/download/meltiew-vr.apk) |

Android: open the APK and allow installing from your browser if asked.
Windows/Linux: unzip and run `Meltiew.exe` / `Meltiew.x86_64`.
macOS: unzip, then right-click Meltiew.app → Open the first time (the app isn't notarized by Apple).
VR headsets: install the VR APK from a computer (Pico: copy it over USB and open it in Files; Quest: developer mode and SideQuest or adb). On a computer with SteamVR or WiVRn running, the Windows and Linux versions start in VR by themselves.
iPhone/iPad: open the IPA in SideStore or AltStore, which sign it with your Apple ID (iPhone XS or newer).
The source code lives on the `main` branch.
